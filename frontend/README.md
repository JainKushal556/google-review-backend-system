# Google NFC Review Cards — React Frontend

High-performance, touch-optimized React application built with Vite for Vercel deployment.

## Features
- **Admin Dashboard:** Executive White Theme with real-time analytics, card directory, search, and status toggle.
- **Customer Review Carousel:** Mobile-first 5-star Google review cards carousel with 1-click clipboard copy + direct popup.
- **AI Custom Review Tab:** Allows customers to type their specific notes and generates a polished 5-star review via LangChain.

## Scripts
- `npm run dev`: Starts local Vite development server at `http://localhost:5173`
- `npm run build`: Compiles production bundle into `dist/`
